# Super Store Sales Dashboard – Excel

## Project Overview

This project presents an interactive Super Store Sales Dashboard developed using Microsoft Excel.

The dashboard provides insights into sales performance, transactions, quantity ordered, regions, categories, shipping modes, cities and monthly order trends.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Charts
- Data Analysis

## Dashboard Features

- Total Sales
- Sales Average
- Transactions
- Total Quantity
- Ship Mode Sales %
- Region-wise Transactions
- Monthly Quantity Orders
- Top 5 Cities by Sales
- Category-wise Transactions
- Consumer Type Quantity Ordered
- Year and Region Filters

## Key Analysis

The dashboard allows users to interactively filter the data by region and year and analyze different sales and quantity metrics.
